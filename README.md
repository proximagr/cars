# 🚗 Αυτοκίητα που είχα ή οδήγησα

Στατικό (front-end only) site με όλα τα αυτοκίνητα που είχα ή οδήγησα για μεγάλο διάστημα.
Χωρίς βάση δεδομένων — όλα τα δεδομένα βρίσκονται στο [`data.js`](data.js).

## Δομή

```
Cars/
├── index.html      # Η σελίδα
├── styles.css      # Εμφάνιση / στυλ
├── app.js          # Λογική (κάρτες, φίλτρα, lightbox)
├── data.js         # τα αυτοκίνητα
└── photos/         # Οι φωτογραφίες
```
